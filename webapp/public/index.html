Import Save File

Checking for local CIFI Bridge…

Don't have the bridge running? ADB Bridge is a small local helper that reads your save file over ADB (emulator or USB) so you don't have to find/copy it by hand. It handles CIFI and other games from one install. The installer includes Node.js; the terminal command needs it already installed.

⬇ Windows installer macOS / Linux ⬇ Download Node.js
npx adb-bridge cifi

Run that in a terminal, leave it running, then click Pull from Device above.

Prefer to find the save file yourself?

Real phone, plugged in via USB (browse it from Windows File Explorer):

This PC \ [Your Phone's Name] \ Internal storage \ Android \ data \ com.OctocubeGamesCompany.CIFI \ files

Emulator (e.g. via its own file manager, or ADB): the equivalent Android path is:

/storage/emulated/0/Android/data/com.OctocubeGamesCompany.CIFI/files/DATA.text

Either way, look for DATA.text (or CifiBackup.text in the same folder, a rolling backup). Copy it off the device and drop it below.

Drop DATA.text or CifiBackup.text here, or click to choose a file
Paste the save text instead (cloud emulators, no file access)

For cloud emulators (LDCloud/LDPlayer Cloud, BlueStacks Cloud, Genymotion Cloud) and any setup where the file can't reach this browser. The save is plain text, so the clipboard carries it perfectly — the hard part is getting at it, because it lives in Android/data/, which Android 11 and later block for ordinary file-manager apps.

Try these in order — the first one that works is fine:

  1. The emulator's own file manager / file transfer. Cloud emulators usually expose a files panel or shared folder in their web UI that is not subject to the Android app restriction. Download DATA.text from /storage/emulated/0/Android/data/com.OctocubeGamesCompany.CIFI/files/ and use the file drop above instead — that's the easiest route if it's available.
  2. The device's built-in Files app. The system file manager is often still allowed into Android/data where third-party ones are not. Open the file, select all, copy, paste below.
  3. Move the account to a device you can read. CIFI has cloud save — sign in on the cloud emulator, sync, then sign in on a phone or a local emulator and pull the save there with npx adb-bridge cifi or its file manager.

Not verified against LDCloud directly — if none of these work, say which step failed and what you saw, and the instructions can be corrected rather than guessed at.
